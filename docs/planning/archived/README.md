# Archived planning

Planning docs whose work is done, or whose framing the project moved past.

**Kept rather than deleted, because a plan records why.** A finished doc still
says what was considered and rejected, and that is the part nobody reconstructs
from the code. What it must not do is read as current — anything in this
directory describes a decision already taken or already abandoned, and nothing
here should be acted on.

Live planning is one directory up.
